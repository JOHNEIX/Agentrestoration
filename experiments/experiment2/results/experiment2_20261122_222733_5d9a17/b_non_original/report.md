# 实验二：排除 B 返回原图试次后的统计

从 60 个配对试次中排除 B 返回原图的 3 次，保留 57 次。
按原始记录中的 `B.output_is_input` 筛选，A、C 同步保留相同的场景与重复，形成配对比较。
